# ⭕ uM-FPU
Le Micromega uM-FPU est un coprocesseur dédié, traitant des nombres en virgule flottante et des entiers sur 32 bits ; il est particulièrement conçu pour décharger les microcontrôleurs aux ressources limitées les tâches telles que les calculs mathématiques complexes, les opérations matricielles, les transformées de Fourier rapides [FFT](https://fr.wikipedia.org/wiki/Transformation_de_Fourier_rapide) et l'analyse de trames GPS [NMEA](https://fr.wikipedia.org/wiki/NMEA_0183), via des interfaces SPI ou I2C.
