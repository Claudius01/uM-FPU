# ⭕ uM-FPU
Le Micromega [uM-FPU V3.1](Documentations/uM-FPU-V3_1-Datasheet.pdf) est un coprocesseur dédié, traitant des nombres en virgule flottante et des entiers sur 32 bits comme le ferait une calculatrice programmable scientifique.

Celui-ci est particulièrement conçu pour décharger les microcontrôleurs aux ressources limitées des tâches telles que les calculs mathématiques complexes, les opérations matricielles, les transformées de Fourier rapides [FFT](https://fr.wikipedia.org/wiki/Transformation_de_Fourier_rapide) et dans une moindre mesure l'analyse de trames GPS [NMEA](https://fr.wikipedia.org/wiki/NMEA_0183), via des interfaces SPI ou I2C.
